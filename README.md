# 词序 · 雅思阅读与听力词汇

一个可以直接在浏览器中使用的雅思词汇学习网站，包含阅读词汇、听力答案词听写、听力同义替换配对、错词复习和 PDF 生词导入。

## 在线使用

[打开词序](https://dreamdavidmit-glitch.github.io/cixu-words/)

## 主要功能

- 阅读：30 个 List、3,000 个词，按每组 10 词学习和检测。
- 听力：答案词需要完成“听音写词 + 选择中文意思”。
- 同义替换：把卷面词、原文替换词和中文意思进行配对。
- 复习：记录拼写错、词义错、反应慢和配对错，并按间隔安排复习。
- 导入：可导入 PDF 或粘贴文本，把做题时遇到的生词穿插到学习组中。
- 离线优先：词表、词典和读音随网页提供，学习进度保存在当前浏览器中。
- GitHub 云进度：可连接单独的私有仓库，自动保存并在其他设备恢复最新学习进度。

## 使用提醒

网站始终先把进度保存在浏览器本地。连接“设置 → GitHub 云进度”后，还会约每 45 秒把变化合并保存到私有的 `cixu-progress` 仓库；新设备连接同一个仓库后会自动读取。GitHub 密钥只保存在对应设备的浏览器中，不会提交到公开的网站仓库。

阅读释义以 [ECDICT](https://github.com/skywind3000/ECDICT) 为基础整理，许可信息见 [`dist/ECDICT-LICENSE.txt`](dist/ECDICT-LICENSE.txt)。听力词汇根据用户提供的学习资料整理；本仓库不包含原始 PDF。

更完整的操作说明见 [使用说明.md](使用说明.md)。
